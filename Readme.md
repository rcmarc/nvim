## My Neovim config

Trying to keep it simple, few plugins, I don't need much.

* Package manager: vim.pack
* Color scheme: Tokyonight and transparent background.
* Git: Fugitive - I though I could live without a plugin for Git but this plugin is just great
* LSP: No extra plugins for this, using `vim.lsp.completion` for autocomplete.
* Finder: good old Telescope.
